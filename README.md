# ⏱️ Cronômetro em Java

Cronômetro minimalista desenvolvido em **Java** utilizando **Swing** para criação da interface gráfica.

O projeto permite iniciar, pausar e zerar o cronômetro através de uma interface simples e intuitiva.

## 🚀 Funcionalidades

- ▶️ Iniciar o cronômetro
- ⏸️ Pausar o cronômetro
- 🔄 Zerar o cronômetro
- ⏱️ Exibição do tempo no formato `HH:MM:SS`
- 🖥️ Interface gráfica utilizando Java Swing

## 🛠️ Tecnologias utilizadas

- **Java**
- **Java Swing**

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/cronometro-java.git
```

### 2. Entre na pasta

```bash
cd cronometro-java
```

### 3. Compile o programa

```bash
javac Main.java
```

### 4. Execute

```bash
java Main
```
